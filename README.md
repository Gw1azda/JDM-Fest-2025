# JDM Fest 2025

JDM Fest 2025 is a multi-page website created as a web development project based around a fictional Japanese car festival.

The website was built using HTML, CSS and JavaScript and includes a range of interactive features such as responsive navigation, a countdown timer, image galleries, forms and a merchandise section.

## Live Website

[View the live website](https://gw1azda.github.io/JDM-Fest-2025/)

## Features

- Multi-page website design
- Responsive navigation with a mobile hamburger menu
- Video homepage banner
- Live event countdown timer
- Featured car sections with image hover effects
- Event listings and schedule
- Featured guest section
- Interactive image gallery with lightbox
- Contact form
- Car registration form
- Merchandise catalogue
- Shopping cart interface
- Mock checkout and payment page
- Previous drift competition winners page
- FAQ section
- Social media links

## Pages

### Home

The homepage introduces JDM Fest 2025 and includes a video banner, event countdown, featured cars and links to other areas of the website.

### Events

Displays the festival events, including a car show, drift exhibition and meet and greet. It also includes an event schedule and featured guests.

### Gallery

An interactive gallery of Japanese cars. Clicking an image opens a larger lightbox view with additional information.

### Merchandise

Displays fictional JDM Fest merchandise and includes a basic JavaScript shopping cart system.

### Contact

Contains a general contact form as well as a separate form for registering a car for the event.

### Winners

Displays the podium results from a previous fictional JDM Fest drift competition.

### Useful Information

Contains event information, contact details, frequently asked questions and additional resources.

### Payment

A mock payment page created for demonstration purposes as part of the merchandise checkout process.
